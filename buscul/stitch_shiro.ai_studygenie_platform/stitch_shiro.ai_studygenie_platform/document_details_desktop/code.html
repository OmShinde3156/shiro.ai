Understanding Backpropagation

Backpropagation, short for "backward propagation of errors," is an algorithm for supervised learning of artificial neural networks using gradient descent. Given an artificial neural network and an error function, the method calculates the gradient of the error function with respect to the neural network's weights.

1. The Forward Pass

Before we can calculate the error and propagate it backwards, we must first perform a forward pass. This involves passing input data through the network's layers, applying weights, biases, and activation functions until a prediction is generated at the output layer.

z^(L) = W^(L) * a^(L-1) + b^(L)
a^(L) = σ(z^(L))

2. Calculating the Loss

Once the forward pass is complete, the network's prediction is compared to the actual target value using a loss function (e.g., Mean Squared Error or Cross-Entropy). This loss value quantifies how far off the prediction was.

3. The Backward Pass

This is the core of the algorithm. We use the chain rule from calculus to compute the partial derivative of the loss function with respect to each weight and bias in the network. This tells us how much a small change in a specific weight would affect the overall error.

Crucial Concept: The Chain Rule

The chain rule allows us to decompose the complex derivative of the loss with respect to a weight deep in the network into a product of simpler derivatives from the layers above it.
