## 4. CURRENT ARCHITECTURE (STABLE)
### Frontend (React/Vite)
- **Visualization:** Recharts (Analytics), CSS Bento Grids
- **State:** Context API (Auth, Podcast, Global)
- **Layout:** Collapsible Neon Sidebar (20px -> 64px)

### Backend (FastAPI/Python)
- **Database:** SQLite (Relational) + ChromaDB (Vector)
- **AI Models:** Groq (Llama 3.3) & OpenAI
- **Logic:** SM-2 (Flashcards), Graph-Augmented RAG (Triplets), Master-Brain Orchestration (Progress/Timetable context)

---

## 5. FUTURE ROADMAP (PRIORITY)
1. **Migration:** SQLite → PostgreSQL (Concurrency support).
2. **Workers:** Implementation of Celery/Redis for background Audio/PDF processing.
3. **Storage:** Local Storage → MinIO/S3 for scalable asset hosting.
4. **UX:** Global search and real-time WebSocket notifications.
